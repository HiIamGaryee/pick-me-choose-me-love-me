# 🚀 Smart Contract Deployment Guide for PickMe ChooseMe LoveMe

## 📋 WHAT YOU NEED TO DO TO DEPLOY SMART CONTRACTS

### **Step 1: Get Your Private Key** 🔑

You need this to sign the deployment transaction.

**How to get it:**
1. Open MetaMask
2. Click the three dots menu (⋮) next to your account
3. Click "Account Details"
4. Click "Export Private Key"
5. Enter your MetaMask password
6. Copy the private key (starts with 0x)

**⚠️ WARNING**: Never share this key with anyone! It has full control of your wallet.

**Example**: `0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef`

### **Step 2: Update .env File** 📝

Open your `.env` file and replace:
```env
PRIVATE_KEY=your_private_key_here
```

With your actual private key:
```env
PRIVATE_KEY=0xYOUR_ACTUAL_PRIVATE_KEY_HERE
```

### **Step 3: Get Pyth Entropy Address** 🔗

You need the Pyth Entropy contract address for Sepolia testnet.

1. Go to: https://docs.pyth.network/entropy
2. Find the "Sepolia testnet" contract address
3. It will look like: `0x1234...` (a long hex address)

### **Step 4: Update Deployment Script** 📝

Edit `scripts/deploy.js` and replace line 9:
```javascript
sepolia: "0x0000000000000000000000000000000000000000", // TODO: Replace
```

With the actual Pyth address:
```javascript
sepolia: "0xYOUR_PYTH_ENTROPY_ADDRESS", // Actual address
```

### **Step 5: Get Testnet ETH** 💰

You need Sepolia testnet ETH to pay for gas fees.

1. Go to: https://sepoliafaucet.com/
2. Enter your wallet address
3. Request testnet ETH
4. You'll need about 0.1 ETH for deployment

**Alternative faucets:**
- https://sepolia-faucet.pk910.de/
- https://www.alchemy.com/faucets/ethereum-sepolia

### **Step 6: Deploy the Contracts** 🚀

```bash
# Make sure you're in the project directory
cd /Applications/XAMPP/Project/pick-me-choose-me-love-me

# Compile the contracts
npx hardhat compile

# Deploy EntropyConsumer contract
npx hardhat run scripts/deploy.js --network sepolia

# Deploy Boost contract  
npx hardhat run scripts/deployBoost.js --network sepolia
```

### **Step 7: Save Contract Addresses** 📝

After deployment, you'll see output like:
```
EntropyConsumer deployed to: 0xABC123...
Boost deployed to: 0xDEF456...
```

Update your `.env` file:
```env
REACT_APP_ENTROPY_CONSUMER_ADDRESS=0xABC123...
REACT_APP_BOOST_CONTRACT_ADDRESS=0xDEF456...
```

### **Step 8: Verify Contracts** ✅

1. Go to: https://sepolia.etherscan.io/
2. Search for your deployed contract addresses
3. Verify they're deployed successfully

### **Step 9: Restart Your App** 🔄

```bash
npm start
```

---

## ⚠️ IMPORTANT NOTES

1. **Testnet Only**: Deploy to Sepolia testnet first (not mainnet)
2. **Keep Keys Secret**: Never share your private key
3. **Gas Fees**: You'll need ETH for gas (use testnet ETH!)
4. **Backup Keys**: Store your private key securely

## 🆘 TROUBLESHOOTING

### "Insufficient funds"
→ Get more Sepolia testnet ETH from faucet

### "Invalid private key"
→ Make sure your private key starts with 0x and is 64 characters

### "Contract address not found"
→ Get the correct Pyth Entropy address from their docs

### "Compilation errors"
→ Run `npm install` and `npx hardhat compile`
