# 🚀 SoulMatch Complete Deployment Guide

This guide will help you deploy both the EntropyConsumer and Boost smart contracts for your SoulMatch dating app.

## 📋 Prerequisites

Before starting, make sure you have:

- ✅ Node.js installed (version 16 or higher)
- ✅ npm or yarn package manager
- ✅ A MetaMask wallet with Sepolia testnet ETH
- ✅ API keys for Infura/Alchemy
- ✅ Private key for deployment wallet
- ✅ PYUSD tokens for testing (optional)

## 🔑 Step 1: Get Required API Keys

### 1.1 Infura API Key
1. Go to [https://infura.io/](https://infura.io/)
2. Create a free account
3. Create a new project
4. Copy the Project ID (this is your API key)

### 1.2 Alchemy API Key (Alternative to Infura)
1. Go to [https://www.alchemy.com/](https://www.alchemy.com/)
2. Create a free account
3. Create a new app
4. Copy the API key

### 1.3 Get Sepolia Testnet ETH
1. Go to [https://sepoliafaucet.com/](https://sepoliafaucet.com/)
2. Enter your wallet address
3. Request testnet ETH (you'll need ~0.1 ETH for deployment)

### 1.4 Get PYUSD Tokens (Optional)
1. Visit [PayPal PYUSD](https://www.paypal.com/us/digital-wallet/paypal-stablecoin)
2. Get PYUSD tokens for testing boost purchases
3. Or use mainnet PYUSD address for testing

## 🔧 Step 2: Update Environment Variables

### 2.1 Update .env File
Open your `.env` file and replace the placeholder values:

```env
# Web3 Configuration
REACT_APP_WALLETCONNECT_PROJECT_ID=your_actual_walletconnect_project_id
REACT_APP_ALCHEMY_API_KEY=your_actual_alchemy_api_key
REACT_APP_INFURA_API_KEY=your_actual_infura_api_key

# Blockchain Network Configuration
REACT_APP_CHAIN_ID=11155111
REACT_APP_RPC_URL=https://sepolia.infura.io/v3/your_actual_infura_api_key

# App Configuration
REACT_APP_APP_NAME=SoulMatch
REACT_APP_APP_DESCRIPTION=Web3 Dating Platform

# Smart Contract Addresses (will be updated after deployment)
REACT_APP_ENTROPY_CONSUMER_ADDRESS=0x0000000000000000000000000000000000000000
REACT_APP_BOOST_CONTRACT_ADDRESS=0x0000000000000000000000000000000000000000
REACT_APP_PYUSD_ADDRESS=0x0000000000000000000000000000000000000000

# Private Key for Deployment (DO NOT COMMIT TO GIT)
PRIVATE_KEY=your_actual_private_key_here
```

### 2.2 Get Your Private Key
⚠️ **IMPORTANT**: Never share your private key publicly!

1. Open MetaMask
2. Click on the three dots menu
3. Select "Account Details"
4. Click "Export Private Key"
5. Enter your password
6. Copy the private key (starts with 0x)

## 🌐 Step 3: Get Contract Addresses

### 3.1 Find Pyth Entropy Addresses
1. Go to [https://docs.pyth.network/entropy](https://docs.pyth.network/entropy)
2. Look for "Contract Addresses" section
3. Find the Sepolia testnet address
4. Copy the address

### 3.2 Find PYUSD Addresses
1. Go to [https://www.paypal.com/us/digital-wallet/paypal-stablecoin](https://www.paypal.com/us/digital-wallet/paypal-stablecoin)
2. Find the official PYUSD contract addresses
3. Use mainnet address: `0x6c3ea9036406852006290770BEdFcAbC0a3f8f6c`
4. Or find Sepolia testnet address if available

### 3.3 Update Deployment Scripts
Update `scripts/deploy.js` with actual Pyth Entropy address:
```javascript
const entropyAddresses = {
  sepolia: "0xYOUR_ACTUAL_PYTH_ENTROPY_SEPOLIA_ADDRESS",
  mainnet: "0xYOUR_ACTUAL_PYTH_ENTROPY_MAINNET_ADDRESS",
};
```

Update `scripts/deployBoost.js` with actual PYUSD address:
```javascript
const pyusdAddresses = {
  sepolia: "0xYOUR_ACTUAL_PYUSD_SEPOLIA_ADDRESS", // or use mainnet address
  mainnet: "0x6c3ea9036406852006290770BEdFcAbC0a3f8f6c",
};
```

## 🚀 Step 4: Deploy Smart Contracts

### 4.1 Navigate to Project Directory
```bash
cd /Applications/XAMPP/Project/pick-me-choose-me-love-me
```

### 4.2 Install Dependencies
```bash
npm install
```

### 4.3 Compile Contracts
```bash
npx hardhat compile
```

### 4.4 Deploy EntropyConsumer Contract
```bash
npx hardhat run scripts/deploy.js --network sepolia
```

Expected output:
```
Deploying EntropyConsumer contract...
Using Pyth Entropy address: 0x... on sepolia
EntropyConsumer deployed to: 0xYourEntropyContractAddress
Contract verified on Etherscan
```

### 4.5 Deploy Boost Contract
```bash
npx hardhat run scripts/deployBoost.js --network sepolia
```

Expected output:
```
Deploying Boost contract...
Using PYUSD address: 0x... on sepolia
Boost contract deployed to: 0xYourBoostContractAddress
Contract verified on Etherscan
```

### 4.6 Update .env File
After successful deployment, update your `.env` file:
```env
REACT_APP_ENTROPY_CONSUMER_ADDRESS=0xYourEntropyContractAddress
REACT_APP_BOOST_CONTRACT_ADDRESS=0xYourBoostContractAddress
REACT_APP_PYUSD_ADDRESS=0xYourPYUSDAddress
```

## 🛠️ Troubleshooting

### Common Issues and Solutions

#### Issue 1: "Insufficient funds"
**Solution**: Get more Sepolia testnet ETH from faucet

#### Issue 2: "Invalid private key"
**Solution**: Make sure your private key starts with 0x and is 64 characters long

#### Issue 3: "Contract not verified"
**Solution**: Wait a few minutes and check again, or manually verify on Etherscan

#### Issue 4: "Pyth Entropy address not found"
**Solution**: Check the official Pyth documentation for current addresses

#### Issue 5: "PYUSD transfer failed"
**Solution**: 
1. Make sure you have enough PYUSD balance
2. Check if you've approved the contract to spend PYUSD
3. Verify PYUSD contract address is correct

#### Issue 6: "Random number not generating"
**Solution**: 
1. Make sure wallet is connected
2. Check if contract has random number available
3. Wait for Pyth to provide randomness (takes ~3 seconds)
