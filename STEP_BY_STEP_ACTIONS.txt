# 🚀 SoulMatch - Step by Step Action List

## 📋 **PHASE 1: GET API KEYS**

### 1. Get Infura API Key
- **Go to**: https://infura.io/
- **Action**: Create account → Create new project → Copy Project ID
- **Save**: Your Infura Project ID

### 2. Get WalletConnect Project ID  
- **Go to**: https://cloud.walletconnect.com/
- **Action**: Create account → Create new project → Copy Project ID
- **Save**: Your WalletConnect Project ID

### 3. Get Sepolia Testnet ETH
- **Go to**: https://sepoliafaucet.com/
- **Action**: Enter your wallet address → Request ETH
- **Need**: At least 0.1 ETH for deployment

### 4. Get Your Private Key
- **Action**: Open MetaMask → Account Details → Export Private Key
- **Save**: Your private key (starts with 0x)

## 📋 **PHASE 2: UPDATE CONFIGURATION**

### 5. Update .env File
```bash
# Open .env file and replace these values:
REACT_APP_WALLETCONNECT_PROJECT_ID=your_actual_walletconnect_project_id
REACT_APP_INFURA_API_KEY=your_actual_infura_project_id
PRIVATE_KEY=your_actual_private_key_here
```

### 6. Get Pyth Entropy Address
- **Go to**: https://docs.pyth.network/entropy
- **Action**: Find Sepolia testnet contract address
- **Save**: The contract address

### 7. Update scripts/deploy.js
```bash
# Open scripts/deploy.js
# Replace line 9 with actual Pyth address:
sepolia: "0xYOUR_ACTUAL_PYTH_ENTROPY_ADDRESS",
```

### 8. Get PYUSD Address
- **Use**: Mainnet PYUSD address: `0x6c3ea9036406852006290770BEdFcAbC0a3f8f6c`
- **Or find**: Sepolia testnet PYUSD address if available

### 9. Update scripts/deployBoost.js
```bash
# Open scripts/deployBoost.js  
# Replace line 8 with PYUSD address:
sepolia: "0x6c3ea9036406852006290770BEdFcAbC0a3f8f6c",
```

## 📋 **PHASE 3: DEPLOY CONTRACTS**

### 10. Navigate to Project Directory
```bash
cd /Applications/XAMPP/Project/pick-me-choose-me-love-me
```

### 11. Install Dependencies
```bash
npm install
```

### 12. Compile Contracts
```bash
npx hardhat compile
```

### 13. Deploy EntropyConsumer Contract
```bash
npx hardhat run scripts/deploy.js --network sepolia
```

### 14. Copy EntropyConsumer Address
- **Action**: Copy the deployed contract address from terminal output
- **Example**: `0x1234567890abcdef...`

### 15. Deploy Boost Contract
```bash
npx hardhat run scripts/deployBoost.js --network sepolia
```

### 16. Copy Boost Contract Address
- **Action**: Copy the deployed contract address from terminal output
- **Example**: `0xabcdef1234567890...`

## 📋 **PHASE 4: UPDATE FRONTEND**

### 17. Update .env with Contract Addresses
```bash
# Add these lines to .env:
REACT_APP_ENTROPY_CONSUMER_ADDRESS=0xYourEntropyContractAddress
REACT_APP_BOOST_CONTRACT_ADDRESS=0xYourBoostContractAddress
REACT_APP_PYUSD_ADDRESS=0x6c3ea9036406852006290770BEdFcAbC0a3f8f6c
```

### 18. Start Development Server
```bash
npm start
```

## 📋 **PHASE 5: TEST FEATURES**

### 19. Test Wallet Connection
- **Action**: Open browser → Connect wallet
- **Check**: Wallet button shows connected

### 20. Test Random Date Generation
- **Action**: Click "Today Soul Most Meet U 🔗" button
- **Check**: Shows "Generating Random Match..." then displays random date

### 21. Test Boost Purchases
- **Action**: Go to "Premium Boosts" tab
- **Check**: Can see boost options and pricing

### 22. Test AI Features
- **Action**: Go to "AI Match" tab
- **Check**: Can set preferences and get AI recommendations

## 📋 **PHASE 6: VERIFY DEPLOYMENT**

### 23. Check Contracts on Etherscan
- **Go to**: https://sepolia.etherscan.io/
- **Action**: Search for your contract addresses
- **Check**: Contracts are deployed and verified

### 24. Test All Features
- **Action**: Test wallet connection, random generation, boosts, AI
- **Check**: Everything works without errors
